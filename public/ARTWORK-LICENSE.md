Streetx modifications: transparent viewBox padding is cropped without rescaling
the original artwork. Raised-planter variants recolor flowers or hide the named
flowers / grass layers. Side scenes use the original building, fence, parking,
grass and waterfront vectors. Apartment storey bands are repeated between a
single roof and storefront; the waterfront's water-only layer extends horizontally.
Those modified illustrations are available under the same
CC BY-SA 4.0 license. They are not endorsed by the original artists.

The original artwork uses one SVG coordinate unit per centimetre. Streetx keeps
that scale constant when a lane is resized. Only explicit camera zoom changes the
display size of artwork.

Frontages are registered to the source illustration's land-contact datum, not
its bounding-box bottom. Microvans use their native y=180 cm tyre-contact datum.
